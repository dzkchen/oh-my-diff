# Extension review register

These are source and functional reviews of release candidates; each entry's
tested host and API versions are in [`index.json`](index.json). These reviews
do not qualify a public support promise, a OMD+ default, task value over
configured Codex, or independent community use. Development-only sources are in
[`development.json`](development.json).

Installed source is separate from activation, and none of these entries is a
supported release package yet.

| Development entry | Reason it stays out of the reviewed candidate index |

The reviewed gap routing is recorded in [the index guide](README.md#workflow-gap-routing).
Structural editing and mechanical patch recovery have selected trials. Native/configured
Codex remains the current path until a package passes the release support gate.

The 2026-09-26 updates keep `omd-artifact-reading` as a reviewed candidate: plugin-owned GitHub virtual reads have local fixture evidence, while public support remains unqualified. `omd-anchored-edit` is a separately installed public-API component. On 2026-09-27 the maintainer accepted the advisor mod on local evidence without real-model qualification; it remains an inactive candidate with live access, quality and savings unverified.
