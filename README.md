# Oh My Diff

Oh My Diff (`oh-my-diff`, identifier prefix `omd`) is a focused patch set for
the open-source Codex CLI/runtime. It keeps `codex` as the launch command and
shares Codex configuration, authentication, instructions, and compatible
sessions.

The project was previously called CAI / Cheaper AI. New project-owned names use
Oh My Diff and `omd`; frozen benchmark identifiers and retained audit evidence
keep their original bytes and remain supported by the benchmark compatibility
mapping.
