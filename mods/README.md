# @oh-my-diff/mod-api

The TypeScript SDK for Oh My Diff mods: API `0.2.0-experimental.5` for Codex `0.162.1`, on Apple Silicon macOS with
Node 24.18 or a later 24.x. OMD installs it with `omd-mod-author`, `omd-mod` and `omd`; it isn't published to npm.

```sh
omd-mod-author create ./my_mod my_mod
```

- [Write your first mod](../docs/write-a-mod.md): create, test, run, install and share a mod.
- [API reference](REFERENCE.md): every operation, event and screen surface.
- [Agent mod guide](../docs/AGENT_MOD_GUIDE.md): the same path, written for coding agents.
