# Pi resources candidate

This API 0.2 mod discovers `.pi/prompts/*.md` and `.pi/skills` in the current repository, and expands one named prompt with Pi's quote-aware positional arguments. Prompt discovery reads at most 128 direct entries of 16 KiB each. Skill discovery visits at most 1024 entries to depth 8, treats a directory with `SKILL.md` as one skill root, includes root-level Markdown files, and skips hidden directories and `node_modules`. It applies bounded `.gitignore`, `.ignore`, and `.fdignore` rules with common glob and negation forms. Unsupported ignore syntax fails closed; unsupported frontmatter produces a diagnostic. A skill requires a description.

The mod verifies read hashes, rechecks selected source and ignore-file hashes after reading, and checks a workspace candidate around discovery. It rejects symlinks and truncated listings, and bounds aggregate results to 128 KiB. Results include scope, source path and SHA-256. Prompt descriptions use a bounded single-line frontmatter subset or the first non-empty body line. Discovery does not execute resources or grant trust to their content.

An optional `user_agent_dir` setting points to a canonical absolute Pi user-agent directory containing `prompts` and `skills`. A declared, hash-bound package script reads that directory through sandboxed, read-only `exec.run`, returning a thread-scoped paged artifact that the mod consumes in the same callback. It checks source listing and file hashes, keeps project resources ahead of same-named user resources, and expands user prompts only when the project has no matching prompt. The configured path is fixed by the package setting; tool inputs cannot select another directory. If the sandbox denies the directory, discovery fails closed. The `/pi` command lists available prompts or submits `/pi NAME ARGUMENTS` with exact expansion through the public command API. The compiled-host and direct Node fixtures use private local user-agent directories.

Prompts are invoked as `/pi NAME ARGUMENTS` rather than one `/pi:<name>` command per prompt. YAML frontmatter and ignore rules are bounded subsets that pass the retained Pi 0.74 discovery and argument fixtures; parent ignore rules outside each skill root and complex patterns fail closed or are not reproduced. This package is a development candidate.
