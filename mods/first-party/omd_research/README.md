# Lead-requested source gathering

`omd_research` uses API `0.2.0-experimental.1` and `OMD_MODE=omd`. It remains opt-in: set `enabled: true` after installing and trusting the package. `preset` names a configured worker route and defaults to `research_luna`. The mod starts no lifecycle work. Both installation profiles use the same route and grant requirements.

The mod owns admission, briefing, tool selection, scope checks and result validation. It accepts a precise question, three to twelve explicit repository/HTTPS scopes, a short source brief, at least four expected sources, and reading versus briefing/handoff estimates. Already located, small or uneconomic questions stay with the lead. The estimates are assertions to review, not measured savings. The UTF-8 briefing packet is at most 5.5 KiB. The worker returns at most six concise findings and explicit uncertainty, with exact file hashes/quotes or canonical source URLs. The mod rechecks file bytes before consuming the result; web quotes remain worker claims and decisive sources must be opened by the lead. Implementation and architecture decisions remain with the lead.

Only an available `routes.list` entry with a `worker` role and model `gpt-6-luna` is accepted. Configure it in the mod store's `host.json`, including its allowed mods, read/search tools, rates and `grant: {path, sha256}`. A subscription route requires `included_subscription: true`, zero monetary reservation and the native ChatGPT authentication checks. This consumes subscription allowance.

Paid API access instead requires nonzero reserved exposure and a separately hashed grant containing `paid_api_key: true`. Both grant types bind schema 1, repository identity, provider, model, responses URL and `revocable: true`; subscription grants contain `included_subscription: true`. The host rechecks exact grant bytes before every request and rejects mixed billing declarations. Grant files are operator actions, never something the mod or agent may create to authorize itself. There is no subscription-to-API fallback. See the public API reference for the host contract. A configured route or logged-in account does not establish access to this model.

The worker runs in a read-only sandbox, cannot spawn children, and shares the task's native allowance. Its tools may include `exec_command` for search; the sandbox, not the tool list, is what prevents writes. The mod waits through up to 20 host waits of at most 30 seconds each, bounded by the worker deadline, before cancelling. Briefing, model/tool requests, handoff, retries and cancellation remain accounted by the host. Unpriced hosted search is denied; there is no silent paid fallback. The mod cancels incomplete workers and does not consume malformed or stale evidence as a usable answer.

Muse Contributor or Claude alternatives are not currently selected or qualified by this package. Their access, terms, tools and allowance require separate verification before an additional preset can be admitted. This does not claim that `gpt-6-luna` is available on any particular public API or account.

Local deterministic tests prove admission, exact-preset denial, narrowed tools, result/file-revision validation, cancellation and disabled behavior. The maintainer accepted this local implementation on 2026-09-27 with real-model qualification outside Batch 2 scope. Live access, paid-route compatibility and representative value remain unverified. This acceptance does not enable the mod or grant model use. Any future savings claim requires comparing direct lead reads against research on a broad repository trace, a multi-source compatibility question and a current-source question, counting briefing, duplicate reads, search charges, handoff, retries and failures under a separately agreed spending/runtime allowance.
