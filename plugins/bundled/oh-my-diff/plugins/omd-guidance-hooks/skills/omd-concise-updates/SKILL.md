# OMD concise updates

Use this skill only for lead-to-user communication.

Write short ordinary-language sentences. State the current outcome first, then the next relevant action. Avoid telegraphic wording and a persona.

Preserve the requested scope. Distinguish verified facts from uncertainty. Keep useful evidence references, limitations, blockers, and incomplete work. Ask any clarification required for safe progress as a direct understandable question.

Do not use this skill to shape worker output or replace the native structured-report schema.
